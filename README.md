# vivek — D2C Storefront Demo

A polished static storefront demo for the Vivek Motte / Vivek Egg concept, focused on product presentation and a simple purchase-flow prototype.

> This is a **UI/product demo**, not a live commerce system. No real payment or fulfillment is performed.

## Included

- Responsive cream-and-teal visual system.
- Landing page and product presentation.
- Quantity controls.
- LocalStorage cart persistence.
- Cart drawer.
- Demo checkout flow.
- Generated demo order ID.
- GitHub Pages deployment workflow.

## Demo data

All prices, nutrition values, reviews, product details and order records are fictional and illustrative.

## Run locally

The site is static and has no framework build step. Open index.html directly or serve the directory with a static server such as `npx serve .`.

## Deployment

The repository includes a GitHub Pages workflow. Enable GitHub Actions as the Pages source and push to the configured branch.

## What this project demonstrates

- Product-focused UI design.
- Client-side state management.
- Browser storage.
- Responsive layouts.
- Static-site deployment.

## Not implemented

- Real payments.
- Real inventory.
- Order backend.
- User accounts.
- Secure payment handling.
- Production fulfillment integration.
